# 未采纳的预加载候选

两个补丁都以产品 `67be06fc235c1498fe33b41d6fad660b12f94089` 为基底，
只含公开产品代码，不含数值观察器、设备信息、图片或应用数据。

- `precache-A-postframe.patch`：原窗口策略保留，仅合并到帧后。
- `precache-B-selection.patch`：同样帧后合并，窗口仅在已接受选页及生命周期变化后更新。

二者用于复现实验，不应用于正常工作树。A 没有减少窗口重排或整体 CPU；
B 减半重排，但正向长按多产帧且 CPU 重复升高，因此均撤回。
补丁以零行上下文导出，避免补丁中的空白上下文触发仓库空格检查；在一次性导出中
复现需用 `git apply --unidiff-zero`。其产品内容与本地带完整上下文的封存补丁相同。
测试 cap 128 MiB、观察器和准确 APK 散列详见 report.md 第八轮及对应结果。
原始大型 Trace 与 APK 继续只保留本地。
