# 手机界面第五轮：固定卡片与等待输入

工作分支 `codex/agent-center-tab`，本地和实时 fork 的共同基线 `db641974c2587af2e021a1e4316550ccbdbab820`；产品和测试定稿 `d44f7cf7c72d2e5686ca28a1e45baffc63a0e7e7`。仍用 Flutter 3.47.9、Dart 3.13.7 和锁定 Prism `8f5fc22`；不调整依赖、原生打包、存储与阅读算法。

## 左侧收藏面板

- 点当前目录仍从物理左侧进入。实际卡片在同一安全区／键盘状态下始终用最大宽高布局；窄态露出可用区域 40% 宽、86% 高。横拖只移动卡片并放开裁剪窗口，内容没有随每个拖动样本压缩或换行。裁剪区外不接收点击；右侧把手、关闭、搜索、目录选择和子目录展开保持独立。
- 目录数量与名称在同一行，数量在物理左边，名称在右边；窄态首先露出名称和操作，向右拉再露出左侧数量。未知网络数量不伪造 0，保留完整无障碍名称/数量。保留本地和网络目录、搜索、滚动、IME、RTL 与手势取消。在 `mobile_side_sheet.dart`、`favorite_folder_browser.dart`、`mobile_folder_sheet_widgets.dart`。

## 全局与收藏搜索

- 全局搜索从实际点击点（顶部按钮、首页搜索输入入口、详情／来源标签等）或真实输入光标展开成同心圆。一次裁剪、一次 `drawCircle`，没有逐帧折射、复杂路径或边缘回弹。用最远角计算半径，完全不透明的圆铺满后才淡入页面并留实色背板；返回时收回同一触点位置，减少动效时不播放。无触点的辅助激活或不可测光标用对应控件中心。路由及来源返回的专用参数不变。
- Flutter 为 Hero 做首帧预布局时，可以让路由临时离屏并报告 `completed`。搜索入口不把它当作真实到达；实际路由完成并绘制到可编辑后才请求一次焦点。检查当前输入节点和内外两层路由，关闭/覆盖/中断时丢弃请求，不对空来源或回到查询页补开。应用不手动发送第二次显示或隐藏键盘命令。
- 收藏搜索在工具栏原来的展开动画结束后才取得焦点。未完成前编辑框不能提前接管键盘；返回、取消、切标签、换控制器或从多选恢复原查询时不重新开键盘，用户随时可在稳定后手动聚焦。保留根/子目录业务查询、原网格与滚动身份。焦点公共检查在 `mobile_search_focus.dart`，入口在 `search_page.dart` 与 `mobile_collection_ui.dart`。

## 阅读器调节画面首开

独立于第四轮的拖滑杆预览/写入改动，对照实际「调节画面」打开路径：原来 ReaderSidebarBinding 先等一个提交后的帧，Prism 又需布局后启动弹层。手机画面面板现在在同一输入事件的微任务加路由，保留 Prism 自己的挂载、弹性、档位和滚动交接。同时在画面面板覆盖期间避免重复采样被遮挡阅读按钮的玻璃；退场动画也保持该作用域，关闭后恢复。仅显示窄屏新工具栏时隔离漫画画面的重绘，正常隐藏工具栏翻页、桌面／TV／墨水屏不新增该图层；面板本身沿用全局材质。确切帧差仅在有界夹具观察，不视为真机 jank 已消除。
